# Security Policy

## Responsible disclosure

If you discover a security or integrity issue, report it privately to the Ryvra security contact channel (contact routing TBD).

Please include:
- affected component and environment
- reproduction steps
- impact assessment
- any proof-of-concept or logs (sanitized)

Do not disclose publicly until coordinated remediation guidance is provided.

## Data integrity and tamper-evidence expectations

- Ledger events must be append-only and auditable.
- Posted history must not be altered or deleted.
- All state transitions and reconciliation actions require traceable audit context.
